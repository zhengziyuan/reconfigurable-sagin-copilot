# v0.7 真实 GIS 与算法中心升级

## 1. 本轮目标

本轮把“可演示地图”和“算法名称列表”升级为两个可实际运行的生产边界：

1. MapLibre 驱动的真实 GIS 画布，所有区域、网格、性能场、链路和节点均绑定 EPSG:4326 坐标。
2. 后端统一算法目录，明确区分原生可运行算法、科研复现和外部适配器。
3. 部署算法与资源算法可以在中文前端中检索、选择、运行并比较。
4. 公开瓦片只作为本地交互演示默认值，正式商用时通过环境变量替换为签约或私有 GIS 服务。

## 2. GIS 架构

### 2.1 数据图层

| 图层 | 数据 | MapLibre 类型 | 交互 |
| --- | --- | --- | --- |
| 底图 | OSM 街道 / Sentinel-2 影像 | Raster source | 平移、缩放、旋转 |
| 场景区域 | `scenario.region.polygon` | GeoJSON fill + line | 场景范围审计 |
| 性能场 | 仿真 `MetricCell[]` | GeoJSON polygon | 指标切换、单元选择 |
| 三维性能场 | 归一化指标值 | fill-extrusion | 2D/3D 切换 |
| 网络链路 | 当前激活节点到锚点 | GeoJSON line | 随拓扑更新 |
| 网络节点 | 卫星、无人机、站点、RIS/MIS/MA | HTML Marker | 选择、拖拽、重新计算 |

### 2.2 底图配置

前端从根目录环境配置读取以下变量：

```text
VITE_GIS_STREET_TILES
VITE_GIS_STREET_ATTRIBUTION
VITE_GIS_SATELLITE_TILES
VITE_GIS_SATELLITE_ATTRIBUTION
```

默认街道瓦片来自 OpenStreetMap，适合普通人工交互演示，不提供 SLA，也不能用于批量预取。商业部署必须替换为以下任一种：

- 已签约的矢量/栅格地图服务；
- 私有部署的 OSM/PMTiles/MBTiles 服务；
- 企业 GIS 平台提供的 WMTS/WMS；
- 项目现场内网的正射影像、DEM 和建筑矢量服务。

### 2.3 GIS 生产化后续接口

- 图层权限：项目级数据源白名单与组织级密钥管理。
- CRS 转换：后端统一转换到 EPSG:4326，保留源 CRS 和转换清单。
- 大数据量：性能场切换为矢量瓦片或 COG，避免一次传输全部网格。
- 离线交付：使用自托管瓦片，不对公共 OSM 服务器做离线下载。
- 中国地图合规：正式面向公众发布前接入具备相应资质和合规能力的地图服务商。

## 3. 算法目录

`GET /api/algorithms` 返回版本化算法目录。每个条目包含：

- `id` 与中文名称；
- 类别和执行引擎；
- `stable`、`research_reproduction` 或 `adapter_ready` 状态；
- 目标、参数、运行时间等级和参考来源；
- 商用界面显示的成熟度标签。

当前原生可运行算法：

| 类别 | 算法 | 作用 |
| --- | --- | --- |
| 部署 | `greedy_fast` | 交互式边际收益部署 |
| 部署 | `exhaustive_pareto` | 小规模精确 Pareto 真值 |
| 部署 | `nsga2_pareto` | 可扩展多目标进化搜索 |
| 部署 | `robust_greedy` | Monte Carlo/CVaR 鲁棒评估 |
| 资源 | `max_sinr` | 最强链路基线 |
| 资源 | `weighted_greedy` | 需求感知快速分配 |
| 资源 | `proportional_fair` | 吞吐与公平折中 |
| 资源 | `ucb_bandit` | 在线探索利用关联 |
| 资源 | `wmmse` | 加权和速率功率控制 |

## 4. NSGA-II 复现

NSGA-II 使用二进制染色体表示候选节点激活状态，并实现：

1. 预算与硬件数量约束修复；
2. 非支配排序；
3. 拥挤距离；
4. 锦标赛选择；
5. 单点交叉与逐位变异；
6. 固定随机种子和仿真结果缓存；
7. Pareto 前沿与逐代收敛轨迹。

所有染色体仍调用同一物理仿真引擎，不使用独立的“假评分函数”。因此结果可以继续绑定场景、模型档位、运行清单和报告证据。

## 5. 资源管控库

一次 `/api/resource-plan` 请求会评估五种方法，并返回当前选择方法以及统一 benchmark：

- 总速率；
- 需求加权速率；
- P5 流速率；
- Jain 公平性；
- 平均功率利用率；
- 接入/回传端到端瓶颈。

WMMSE 从需求加权可行解开始迭代，保存历史最佳加权 SINR 效用，避免数值更新导致最终方案退化。界面显示方法成熟度为“科研复现”，因为当前实现是规划级 SISO 版本，不宣称等同于完整多用户 MIMO 预编码器。

## 6. 验证范围

自动测试覆盖：

- NSGA-II 可行性、Pareto 前沿和收敛轨迹；
- 五类资源算法均可运行并输出统一 benchmark；
- 算法目录版本、成熟度和原生/适配器边界；
- 原有仿真、3GPP/ITU、报告、任务、SQLite 和候选点流程回归。

浏览器验收覆盖：

- 街道与卫星底图切换；
- 2D 与 3D 性能场切换；
- 节点和地理图层加载；
- 算法中心分类、选择与运行；
- 比例公平资源方案和五算法对比结果；
- 页面无横向溢出、地图控件无重叠、控制台无报错。
